# 📚 Examples

This directory contains examples and demos for the AI Newsletter Generator.

## 🚀 Quick Start Examples

### 1. Email Setup (`setup_email.py`)
Interactive script to set up Gmail authentication:
```bash
python examples/setup_email.py
```

### 2. Send Demo Newsletter (`send_demo_newsletter.py`)
Generate and send a real newsletter to your email:
```bash
python examples/send_demo_newsletter.py
```

### 3. Email Demo (`email_demo.py`)
Demonstrate email distribution features:
```bash
python examples/email_demo.py
```

### 4. Simple Demo (`demo_simple.py`)
Basic demonstration with dummy data:
```bash
python examples/demo_simple.py
```

## ⚙️ Configuration Examples

### Email Configuration
Copy `email_config_example.json` to `config/email_config.json` and update with your credentials:
```bash
cp examples/email_config_example.json config/email_config.json
```

### Orchestrator Configuration
Copy `orchestrator_config_example.json` to `config/orchestrator_config.json`:
```bash
cp examples/orchestrator_config_example.json config/orchestrator_config.json
```

## 📋 Example Usage Patterns

### Basic Newsletter Generation
```python
from src.newsletter_orchestrator import NewsletterOrchestrator

# Initialize orchestrator
orchestrator = NewsletterOrchestrator()

# Generate newsletter
report = orchestrator.generate_newsletter("Technology Trends")
print(f"Newsletter: {report['newsletter'].title}")
```

### Email Distribution
```python
from src.email_distributor import EmailDistributor

# Initialize distributor
distributor = EmailDistributor()

# Add subscribers
distributor.add_subscriber("user@example.com", "User Name")

# Send newsletter
results = distributor.send_newsletter(html_content, text_content, "Theme")
print(f"Sent to {results['sent_successfully']} subscribers")
```

### Custom RSS Feeds
```python
# Edit config/research_config.json
{
  "sources": {
    "my_news": [
      "https://my-blog.com/feed/",
      "https://my-news-site.com/rss"
    ]
  }
}
```

## 🔒 Security Examples

### Environment Variables
```bash
# .env file
SMTP_SERVER=smtp.gmail.com
SENDER_EMAIL=your-email@gmail.com
SENDER_PASSWORD=your-app-password
```

### Secure Configuration Loading
```python

load_dotenv()

config = {
    "sender_email": os.getenv("SENDER_EMAIL"),
    "sender_password": os.getenv("SENDER_PASSWORD")
}
```

## 🚀 Deployment Examples

### Docker Deployment
```dockerfile
FROM python:3.9-slim

WORKDIR /app
COPY requirements.txt .
RUN pip install -r requirements.txt

COPY . .
CMD ["python", "main.py", "--schedule"]
```

### Cron Job
```bash
# /etc/cron.d/newsletter
0 9 * * 5 /usr/bin/python /path/to/ai-newsletter-generator/main.py --generate
```
